# ⚽ QuadraDas — Plataforma de Locação de Quadras Esportivas

> **QuadraDas** é uma solução completa para simplificar a busca, agendamento e gerenciamento de quadras esportivas, conectando atletas a estabelecimentos de forma rápida, intuitiva e acessível.

## 🚀 Sobre o Projeto

O **QuadraDas** foi projetado para resolver a complexidade no agendamento de quadras. Com uma interface limpa e focada na experiência do usuário, a plataforma oferece:

- **Para os Atletas:** Praticidade na busca por disponibilidade, preços transparentes e reserva em poucos cliques.
- **Para os Administradores:** Um painel de controle completo para gestão de horários, quadras, reservas e usuários.

---

## ⚙️ Funcionalidades Principais

| Módulo | Funcionalidades |
| :--- | :--- |
| **🌐 Visitante (Não Logado)** | • Navegação na página inicial <br> • Consulta e busca/filtro de quadras disponíveis <br> • Detalhes da estrutura, preços e horários <br> • Cadastro de nova conta e Login |
| **👤 Cliente (Logado)** | • Agendamento e realização de reservas <br> • Consulta de histórico de reservas (Futuras e Passadas) <br> • Cancelamento de reservas ativos <br> • Gestão de dados do perfil |
| **🛠️ Administrador** | • Painel Dashboard centralizado <br> • Cadastro, edição e exclusão de quadras <br> • Controle e bloqueio de horários da grade <br> • Gerenciamento completo de reservas e usuários |
